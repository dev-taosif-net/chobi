# Security policy

Chobi opens untrusted media files, so parser bugs matter. Most decoding happens in FFmpeg and
libmpv; vulnerabilities there should also be reported upstream.

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/dev-taosif-net/chobi/security/advisories/new)
rather than a public issue. Include the Chobi version, OS and, if possible, a minimal file that
triggers the problem. You can expect an acknowledgement within a week.
